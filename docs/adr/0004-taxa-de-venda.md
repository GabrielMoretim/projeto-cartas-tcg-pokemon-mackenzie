# ADR 0004 — Taxa de venda do marketplace
**Status:** aceito
**Decisão:** parâmetro `TAXA_VENDA` (padrão 15%, hipótese declarada). O pipeline grava as carteiras com a taxa **e** com 0%; o dashboard alterna entre as duas.
**Sensibilidade (ATAM):** a diferença entre as duas curvas mede o quanto a conclusão depende da taxa. Dólar e CDI não pagam taxa.
